## Overview

Databases lets you browse and edit databases that run on your hosts. It runs the database's own command line client over SSH, so nothing is installed on the host and no database port has to be opened. Each host gets its own tab with saved logins, a table browser, a structure view and a SQL console.

Read the [docs](https://docs.termix.site/plugins/databases) to set it up and use it.

<br />

## Features

- MySQL, MariaDB, PostgreSQL and SQLite
- Saved logins per host with sealed passwords, socket logins and run as another Linux user
- Page, sort and filter table data
- Add, edit and delete rows by primary key
- Columns, types, keys and indexes
- SQL console with history and CSV or JSON export
- Read only logins and read only sessions for users without edit access
